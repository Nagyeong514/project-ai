[1] 전체 요약  
GPU(그래픽 카드)를 워크스테이션 케이스 내 PCIe 슬롯에 삽입하는 장면. 숙련자 특유의 정교한 손가락 조작으로 GPU 브래킷과 슬롯 가장자리 간의 미세한 정렬을 시각적으로 인식하고, 저항 발생 시 즉각적인 힘 조절을 통해 부품 손상을 방지. 래치 잠금 시 ‘딸깍’ 소리와 시각적 수평 상태를 통한 완료 인식이 관찰됨. 전원 커넥터는 삽입 직전에 정렬된 상태에서 단일 손가락으로 약간의 압력을 가해 잠금 클립을 누르는 방식으로 체결.

[2] 작업 구간 구분  
【PCIe 슬롯 삽입】 0~18초  
【래치·잠금 확인】 18~26초  
【전원 커넥터 체결】 26~34초  
【브래킷 나사 고정】 34~39초  
【최종 검증】 39~40초  

[3] 단계별 동작 분석  

【PCIe 슬롯 삽입】 0~18초  
• 주도손: 오른손 엄지·검지·중지 (GPU PCB 상면 끝단을 잡음)  
• 보조손: 왼손 검지·중지가 GPU 후면 I/O 브래킷에 접촉, 수평← 약한 힘으로 쏠림 방지  
• 대상: GPU PCB  
• 동작: 밀기  
• 힘·방향:  
　① 접촉 직전: 느림 + 수직↓  
　② 저항 중: 중 + 수직↓ (슬롯 입구 저항 감지 시)  
　③ 저항 소멸 후: 강→약 (클릭 후 즉시 이완)  
• 결과: GPU가 슬롯 내부에 완전히 수직으로 삽입됨, 브래킷이 슬롯 가장자리에 맞춰짐  
• 이전 구간 대비: GPU를 케이스 내 슬롯에 접근하여 정렬 및 삽입 시작  

【래치·잠금 확인】 18~26초  
• 주도손: 오른손 검지·엄지 (래치 클립 가장자리)  
• 보조손: 왼손 검지·중지가 GPU 브래킷 하단에 접촉, 수평↑ 약한 힘으로 고정  
• 대상: PCIe 래치 클립  
• 동작: 누르기  
• 힘·방향:  
　① 접촉 직전: 느림 + 수평→  
　② 저항 중: 약 + 수평→ (래치가 잠금 상태인지 확인)  
　③ 저항 소멸 후: 유지 (래치가 자동으로 잠금된 상태 확인)  
• 결과: 래치가 완전히 잠김 → ‘딸깍’ 소리 발생  
• 이전 구간 대비: GPU 삽입 후 래치 잠금 점검  

【전원 커넥터 체결】 26~34초  
• 주도손: 오른손 검지·엄지 (전원 커넥터 플러그)  
• 보조손: 왼손 검지·중지가 케이스 내 전원 포트 가장자리에 접촉, 수평← 약한 힘으로 고정  
• 대상: GPU 전원 커넥터  
• 동작: 밀기  
• 힘·방향:  
　① 접촉 직전: 느림 + 수직↓  
　② 저항 중: 약 + 수직↓ (커넥터가 포트에 맞춰짐)  
　③ 저항 소멸 후: 즉시 이완 (커넥터가 완전히 잠김)  
• 결과: 전원 커넥터가 포트에 완전히 삽입됨, 잠금 클립이 자동으로 잠김  
• 이전 구간 대비: GPU 본체 삽입 후 전원 연결  

【브래킷 나사 고정】 34~39초  
• 주도손: 오른손 엄지·검지 (나사 헤드)  
• 보조손: 왼손 검지·중지가 GPU 브래킷 베이스에 접촉, 수평↑ 약한 힘으로 고정  
• 대상: GPU 브래킷 나사  
• 동작: 조이기  
• 힘·방향:  
　① 접촉 직전: 느림 + 수직↑  
　② 저항 중: 중 + 수직↑ (나사가 브래킷에 잡힘)  
　③ 저항 소멸 후: 유지 (나사가 완전히 잠김)  
• 결과: 나사가 브래킷에 완전히 고정됨  
• 이전 구간 대비: 전원 연결 후 브래킷 고정  

【최종 검증】 39~40초  
• 주도손: 오른손 검지·엄지 (GPU 상면)  
• 보조손: 왼손 검지·중지가 케이스 내 슬롯 가장자리에 접촉, 수평↑ 약한 힘으로 고정  
• 대상: GPU 전체  
• 동작: 촉각 검사  
• 힘·방향:  
　① 접촉 직전: 느림 + 수평→  
　② 저항 중: 약 + 수평→ (GPU가 수평으로 고정되어 있음을 감지)  
　③ 저항 소멸 후: 유지 (GPU가 완전히 고정됨)  
• 결과: GPU가 수평으로 고정되어 있음, 래치가 잠금 상태  
• 이전 구간 대비: 나사 고정 후 최종 위치 확인  

[4] 숙련자 암묵지 집중 분석  

4-A. PCIe 슬롯 정렬 기법  
- 슬롯 가장자리와 GPU 브래킷의 가장자리가 일치하도록 시각적으로 정렬 (GPU 브래킷 가장자리가 슬롯 가장자리에 맞춰짐)  
- 삽입 전 기울기 보정 없음. GPU가 슬롯 입구에 맞춰 수직으로 삽입됨  
- 브래킷 쪽이 먼저 삽입됨 (GPU 브래킷이 슬롯 가장자리에 맞춰짐)  

4-B. 삽입 힘 프로파일  
- 초기 무게 지지(약) → 첫 저항(중, 슬롯 입구) → 순간 강 압력 → 클릭 후 즉시 이완  
- 힘 전환 트리거: ‘딸깍’ 소리 (래치 잠금 시)  

4-C. PCIe 래치(리텐션 클립) 조작  
- 래치를 열 때: 오른손 검지·엄지가 래치 클립 가장자리에 접촉, 수평→ 약한 힘으로 누름  
- 래치가 자동으로 닫히는가? → 자동으로 닫힘 (‘딸깍’ 소리 발생)  
- 래치 상태 인식: 청각(‘딸깍’ 소리) + 시각(래치가 완전히 잠김)  

4-D. 전원 커넥터 체결  
- 커넥터 방향 정렬: 커넥터가 포트에 맞춰 수직으로 삽입됨  
- 삽입 힘: 약한 힘 (커넥터가 포트에 맞춰짐)  
- 잠금 클립 처리: 커넥터가 포트에 삽입되면 자동으로 잠김  

4-E. 손상 방지 행동  
- GPU PCB에서 손이 닿지 않는 부위 회피: 손가락이 GPU PCB 상면을 직접적으로 닿지 않음  
- 정전기 방지 행동: 관찰되지 않음  
- 과도한 힘 방지 방식: 힘을 약하게 가함 (GPU가 슬롯에 맞춰짐)  

4-F. 완료 인식 신호  
- 작업 완료 신호: ‘딸깍’ 소리 (래치 잠금) + 시각적 수평 상태 (GPU가 수평으로 고정됨)
