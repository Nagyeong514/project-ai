================================================================================

[사용한 프롬프트]

이 영상은 하드웨어 조립 작업 영상이다.
아래 세 단계로 순서대로 분석하라.

=========================
PHASE 1. 초안 행동 기록
=========================

영상을 처음부터 끝까지 보고,
관찰되는 행동을 시간 순서대로 초안으로 기록한다.

각 행동마다 아래 형식으로 출력한다.

[초안 Timestamp: ]
행동:
다루는 객체:
왼손 동작:
오른손 동작:
확인 행동:
결과:

=========================
PHASE 2. 자기 검증 (Verification)
=========================

PHASE 1에서 기록한 각 행동에 대해
아래 검증 질문에 답하여 사실 여부를 확인한다.

각 초안 행동마다 다음 질문에 답한다.

검증 질문:
Q1. 이 행동이 영상에서 실제로 눈으로 확인되었는가? (예 / 아니오)
Q2. 사용한 부품명이 확실한가? 확실하지 않으면 형태로 수정하라.
Q3. 왼손과 오른손 동작이 실제로 관찰된 것인가, 아니면 추측인가?
Q4. 확인 행동(재가압, 육안 확인 등)이 실제로 관찰되었는가?
Q5. 이 행동이 앞뒤 행동과 자연스럽게 연결되는가?

Q1이 '아니오'이면 해당 행동을 삭제한다.
Q2~Q5에서 수정이 필요한 항목은 수정 내용을 명시한다.

=========================
PHASE 3. 최종 행동 로그 출력
=========================

PHASE 2의 검증을 반영하여
수정된 최종 행동 로그를 아래 형식으로 출력한다.

--------------------------------------------------
Timestamp:
행동 분류:
작업 대상 부품 (불확실 시 형태 기술):
파지 위치:
왼손 동작:
오른손 동작:
접촉 객체 및 위치:
힘 방향:
동작 속도 (빠름/보통/느림/정지):
일시 정지 여부 및 지속 시간:
확인 행동:
이전 행동과의 연속성:
결과:
검증 수정 사항 (PHASE 2에서 수정된 내용, 없으면 '없음'):
--------------------------------------------------

규칙:
- PHASE 2에서 사실이 아닌 것으로 판단된 행동은 최종 로그에 포함하지 않는다.
- 부품명 불확실 시 형태(색상, 크기, 모양)로 기술한다.
- 재가압, 재확인, 위치 재조정은 반드시 별도 항목으로 기록한다.
- 래치, 클립 상태 변화는 반드시 기록한다.
- 추측 금지. 보이는 것만 기술한다.

모든 출력은 한국어로 작성한다.
