[프롬프트 2: B_CoT_FewShot]
================================================================================

[사용한 프롬프트]

이 영상은 하드웨어 조립 작업 영상이다.
아래 순서대로 단계적으로 분석하라.

=========================
Step 1. 영상 전체 파악 (CoT)
=========================

영상 전체를 보고 다음을 먼저 파악한다.

- 어떤 종류의 작업이 수행되고 있는가
- 작업자가 다루는 주요 부품은 무엇인가 (불확실 시 형태로 기술)
- 작업 공간에 있는 객체는 무엇인가
- 전체 작업 순서를 3~5문장으로 요약한다
- 특이하게 보이는 행동(멈춤, 재시도, 재가압 등)을 미리 메모한다

=========================
Step 2. 출력 형식 확인 (Few-Shot)
=========================

아래 예시를 반드시 참고하여 Step 3의 출력 형식을 따른다.

=== 예시 시작 ===

Timestamp: 00:01
행동 분류: 부품 파지
작업 대상 부품: 초록색 직사각형 회로기판 (하단에 홈 1개)
파지 위치: 부품 상단 좌우 모서리
왼손: 부품 좌측 상단 모서리를 엄지·검지로 집음
오른손: 부품 우측 상단 모서리를 엄지·검지로 집음
접촉 객체: 없음
힘 방향: 없음
동작 속도: 느림
일시 정지 여부: 없음
확인 행동: 없음
이전 행동과의 연속성: 시작 동작
결과: 부품을 양손으로 수평으로 들어올림

Timestamp: 00:03
행동 분류: 방향 정렬
작업 대상 부품: 초록색 직사각형 회로기판
파지 위치: 부품 하단 좌우 끝
왼손: 부품 하단 좌측을 아래에서 받침
오른손: 부품 하단 우측을 잡고 홈 위치를 슬롯 키에 맞추기 위해 좌우로 미세 조정
접촉 객체: 메인보드 슬롯 키
힘 방향: 수평 (좌우 미세 조정)
동작 속도: 느림
일시 정지 여부: 있음 (약 1초, 홈 위치 육안 확인)
확인 행동: 부품 하단 홈과 슬롯 키 위치를 육안으로 비교 후 정렬
이전 행동과의 연속성: 부품 파지 후 슬롯 위로 이동한 직후
결과: 부품 홈이 슬롯 키와 일치하는 위치에 정렬됨

Timestamp: 00:05
행동 분류: 삽입 가압
작업 대상 부품: 초록색 직사각형 회로기판
파지 위치: 부품 상단 좌우 끝
왼손: 부품 좌측 상단 끝을 엄지로 수직 하방 가압
오른손: 부품 우측 상단 끝을 엄지로 수직 하방 가압
접촉 객체: 메인보드 슬롯
힘 방향: 수직 하방, 양끝 동시 가압
동작 속도: 보통
일시 정지 여부: 없음
확인 행동: 없음
이전 행동과의 연속성: 방향 정렬 완료 직후 삽입
결과: 슬롯 래치 2개가 올라와 잠김

Timestamp: 00:06
행동 분류: 장착 확인 (재가압)
작업 대상 부품: 초록색 직사각형 회로기판
파지 위치: 부품 상단 중앙
왼손: 부품 상단 좌측을 엄지로 가볍게 눌러봄
오른손: 부품 상단 우측을 엄지로 가볍게 눌러봄
접촉 객체: 메인보드 슬롯
힘 방향: 수직 하방, 약한 힘
동작 속도: 느림
일시 정지 여부: 있음 (약 0.5초)
확인 행동: 양손으로 한 번 더 눌러 래치 고정 상태 확인
이전 행동과의 연속성: 삽입 직후 재확인
결과: 래치 고정 상태 확인 완료

=== 예시 끝 ===

=========================
Step 3. 행동 로그 생성
=========================

Step 1에서 파악한 내용을 바탕으로,
Step 2의 예시 형식을 반드시 따라 영상의 모든 행동을 처음부터 끝까지 기록한다.

추가 규칙:
- 부품 이름을 모르면 형태(색상, 크기, 모양, 홈 위치)로 기술한다.
- 영상에서 보이지 않는 것은 '확인 불가'로 표기한다.
- 행동 하나를 여러 Timestamp로 쪼개는 것을 허용한다.
- 재가압, 재확인, 위치 재조정은 반드시 별도 항목으로 기록한다.
- 래치, 클립, 걸쇠의 상태 변화는 반드시 기록한다.
- 영상에서 보이는 사실만 기술한다. 추측 금지.

=========================
Step 4. 최종 요약
=========================

- 전체 행동 수
- 식별된 주요 부품 목록
- 반복 행동 여부 (재가압, 재삽입, 재정렬 등)
- 단순 직선 운동에서 벗어난 행동 (멈춤, 방향 전환, 미세 조정 등)

모든 출력은 한국어로 작성한다.
