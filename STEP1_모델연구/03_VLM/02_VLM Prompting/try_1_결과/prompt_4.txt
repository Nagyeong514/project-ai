============================================================
[사용한 프롬프트]
Analyze this hardware assembly video and output a JSON array.

First, identify what task is being performed by observing:
- The type of component being handled
- The location on the workstation where work is done
- The number of workers and their roles

Then decompose every action into atomic units and output as JSON.

Each action must follow this exact schema:
{
  "timestamp": "MM:SS",
  "action_index": 1,
  "action_summary": "한 줄 요약",
  "component": "부품명 또는 형태 기술",
  "component_confidence": "high/medium/low",
  "contact_on_component": "부품의 어느 부위에 접촉",
  "contact_on_workstation": "워크스테이션의 어느 위치에 접촉",
  "left_hand": "왼손 동작 상세",
  "right_hand": "오른손 동작 상세",
  "force_direction": "수직하방/수평/회전/없음",
  "motion_speed": "빠름/보통/느림/정지",
  "pause_detected": true or false,
  "pause_duration_sec": 숫자 또는 null,
  "verification_action": "확인 행동 기술 또는 null",
  "result": "동작 결과",
  "observable_only": true
}

Rules:
- Output JSON array only. No text outside the array.
- If a field is not observable, use null.
- component_confidence: high=clearly visible, medium=partially visible, low=inferred from context.
- Split every compound action. One timestamp = one atomic action.
- Re-pressing, re-checking, repositioning must each be separate entries.
- Do not name components if not certain. Use shape/color/size description instead.
