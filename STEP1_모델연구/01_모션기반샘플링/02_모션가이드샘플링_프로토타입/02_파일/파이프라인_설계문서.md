## 2. STEP 1 — 모션 스코어 계산

**파일:** `motion_score.py`

### 방식
1초 간격으로 프레임을 샘플링하여 인접 프레임 간 픽셀 절댓값 차이(absdiff) 평균을 모션 스코어로 정의.

```
score(t) = mean( |gray(t) - gray(t-1)| )
```

### 전처리
- **GaussianBlur (5×5)**: 샘플링 전 적용하여 AR 글래스 특유의 고주파 노이즈 억제
- **노이즈 데드존**: score < 1.5이면 0으로 처리 → 미세 진동을 정지로 분류

### 설계 근거
- absdiff는 연산이 단순하고 빠르며 카메라 이동량과 선형적으로 비례
- 1초 간격 샘플링: 30fps 기준 30프레임 중 1프레임만 처리 → 속도 30배 향상, 정밀도 충분
- 광학 흐름(Optical Flow) 대비 방향 정보는 없지만 연산 비용이 낮고 목적(이동량 파악)에 충분

## 3. STEP 2 — 샘플링 전략 비교 및 선택

**파일:** `select_clip.py`

### 3-1. 전략 A: Threshold + AKS

**방식**
1. 상위 75% 모션 점수 이상인 프레임만 추출
2. 인접 구간 병합 (merge_gap 이하 간격)
3. 최소 간격 필터 (coverage_min_gap = 영상길이 ÷ 클립수) 적용

**특징**
- 고모션 구간만 보존 → 모션관련도 높음
- 영상이 짧거나 모션이 고르게 분포하면 클립이 0개 나오는 경우 발생
- 3개 영상에서 단 1개 클립(전체 영상) 선택 → 사실상 필터링 실패

**적합한 경우:** 장시간 영상에서 특정 고모션 이벤트만 추출할 때

---

### 3-2. 전략 B: CDF 역변환 샘플링 (MGSampler)

**방식**
1. 모션 스코어의 누적분포함수(CDF) 계산
2. CDF를 N등분하는 지점의 실제 타임스탬프를 앵커로 선택

```
CDF(t) = Σ score(0..t) / Σ score(전체)
앵커_k = CDF^(-1)( (2k-1) / 2N ),  k = 1..N
```

**특징**
- 모션 밀도가 높은 구간에 앵커가 몰림 → 자연스러운 밀도 비례 샘플링
- 균등성 지표가 높음 (클립이 고르게 분산)
- 모션관련도는 C보다 낮음 (최고점이 아닌 중간값도 선택)

**적합한 경우:** 전체 영상의 흐름을 고르게 요약할 때

---

### 3-3. 전략 C: AKS 시간 윈도우 ArgMax

**방식**
1. 영상을 N개의 시간 구간으로 균등 분할
2. 각 구간 내에서 모션 스코어가 가장 높은 지점을 앵커로 선택

```
window_i = score[ i*W : (i+1)*W ]
anchor_i = argmax(window_i)
```

**특징**
- 각 구간의 최고 모션 지점을 반드시 선택 → 모션관련도 최상(97~98%)
- 시간적 커버리지 보장
- 균등성은 B보다 낮음 (앵커가 구간 내 편향 위치에 몰릴 수 있음)

**적합한 경우:** 각 시간 구간에서 가장 동적인 장면을 추출할 때

---

### 3-4. 전략 선택 기준

세 전략을 동시 실행 후 아래 종합점수로 자동 선택.

```
종합점수 = 커버리지 × 0.40
         + (모션관련도 / 100) × 0.35
         + 균등성 × 0.25
```

| 지표 | 가중치 | 정의 |
|------|--------|------|
| 커버리지 | 40% | `1 - max_gap / 영상길이` — 가장 긴 빈 구간이 작을수록 높음 |
| 모션관련도 | 35% | 선택된 앵커들의 모션 점수 백분위 평균 |
| 균등성 | 25% | `1 - CV(앵커 간격)` — 앵커 간격의 변동계수가 낮을수록 높음 |

**가중치 설정 근거**

세 지표 모두 "높을수록 좋다"는 같지만, 놓쳤을 때의 대가가 다르다. 이 손실의 회복 가능성을 기준으로 우선순위를 정했다.

| 순위 | 지표 | 가중치 | 놓쳤을 때 결과 | 되돌릴 수 있는가 |
|------|------|--------|----------------|------------------|
| 1 | 커버리지 | 40% | 그 구간의 암묵지 후보가 통째로 사라짐 | **불가능** — 클립으로 뽑히지 않으면 다음 단계(YOLO/STT/VLM) 입력 자체가 안 됨 |
| 2 | 모션관련도 | 35% | 정지·무의미 구간이 클립에 섞여 들어감 | **부분 가능** — 클립은 살아있어 후속 단계에서 걸러낼 여지 있음, 단 연산비용 낭비 |
| 3 | 균등성 | 25% | 클립이 특정 구간에 쏠림 | **커버리지가 보완** — 완전히 몰리지만 않으면 치명적이지 않음 |

되돌릴 수 없는 것(커버리지) → 비용만 드는 것(모션관련도) → 미관상 문제(균등성) 순으로 40 > 35 > 25 가중치를 부여했다.

**참고 — 문헌 검토 결과**: MGSampler(ICCV 2021, 전략 B의 원조)와 AKS(CVPR 2025, 전략 A/C 원조)는 유사 개념(관련도·커버리지)을 다루지만 고정 가중치를 명시하지 않는다. AKS는 데이터셋마다 다른 threshold로 대체하고, 대표적 영상요약 reward인 DR-DSN(AAAI 2018)도 두 reward를 가중치 없이 단순 합산한다. 즉 이 분야에서 범용적으로 검증된 가중치는 존재하지 않으며, 태스크 목적(암묵지 보존)에 맞춘 자체 설계값을 쓰는 것이 타당하다.

---

### 3-5. 클립 파라미터 자동 계산

```python
n_clips     = max(3, int(영상길이(초) / 40))   # 40초당 클립 1개, 최소 3개
clip_window = ceil(영상길이 × 0.75 / (n_clips × 2))  # 유지율 75% 목표
```

**clip_window 설계 근거**
- 앵커를 중심으로 앞뒤 clip_window초를 하나의 클립으로 추출
- `n_clips × 2 × clip_window ≈ 영상길이 × 0.75`가 되도록 역산
- 75% 목표: 의미 없는 구간 제거 + 맥락 보존의 균형점

## 4. STEP 3 — 클립 추출

**파일:** `extract_video.py`

### 방식
ffmpeg `-c:v copy` (stream copy) 사용

### 설계 근거
- **재인코딩 없음**: 원본 화질 그대로 유지, 손실 없음
- **속도**: 디코딩·인코딩 없이 컨테이너만 분리 → 거의 즉시 완료
- **용량**: 원본 비트레이트 그대로 → 파일 크기 예측 가능
- `-ss` (seek)를 입력 전에 배치하여 키프레임 기준 고속 탐색

반면 전략 C는 각 구간의 최고점만 잡아 클립이 구간 내 편향 위치에 모이는 경향이 있어 균등성 손해.

## 6. 한계 및 개선 방향

| 한계 | 개선 방향 |
|------|---------|
| 가중치(0.40/0.35/0.25)가 임의값 | 도메인 전문가 평가로 가중치 최적화 |
| absdiff는 이동 방향 무시 | Optical Flow 도입 시 의도적 시선이동 vs 노이즈 구분 가능 |
| clip_window가 고정 비율 | 모션 분포에 따라 동적 조정 |
| 전략 A가 짧은 영상에서 실패 | coverage_min_gap 알고리즘 개선 필요 |
| 다음 단계 연동 없음 | YOLO/STT 결과 피드백으로 샘플링 기준 재조정 가능 |
