# STT 4-arm 비교 실험 보고서 (v2) — 환각 필터 전/후

> 이전 v1(`STT_EXPERIMENT_REPORT.md`, Whisper 3종 비교 → large-v3-turbo 채택)의 후속 실험.
> 서버 이관(RTX2080 8GB×1 → RTX6000×2 48GB, Turing sm75) 후 한국어 특화 모델 2종을 추가해
> 4-arm으로 재비교했고, STT 원본 출력의 환각을 걷어내는 필터를 채점 전 단계에 붙여
> **필터 전/후 점수를 나란히 비교**했다.
>
> **상태**: 예비 스모크테스트(n=4파일×1샘플). 최종 모델 선정 근거로 쓰기엔 표본이 작다 — 5장 참고.
> 날짜: 2026-07-01

---

## 0. 요약

- 4-arm(Whisper large-v3 / large-v3-turbo / Seamless-M4T-v2-Large / Wav2Vec2-XLSR-Korean)을
  CLIP1~4(PC조립 현장 설명, 실제 확보한 대본을 GT로 사용)로 비교했다.
- **필터 전 CER은 전 모델 65~98%대로 비정상적으로 높았다.** 원인을 전사 원문에서 직접 확인한 결과,
  대본 불일치가 아니라 **4종 모두에서 재현된 STT 환각**(모델별로 종류가 다름)이 주범이었다.
- STEP3_전처리팀이 이미 만든 환각 denylist(`transcript_refine.py`)를 재사용 + 확장해
  채점 전 필터로 붙이고(`evaluation/hallucination_filter.py`), 필터 전/후를 같은 샘플로
  다시 채점했다.
- **결과**: Whisper 계열·Seamless는 필터로 CER이 30~47% 개선됐고, **Seamless-M4T-v2-Large가
  필터 후 4개 파일 중 3개에서 최저 CER**로 뒤바뀌었다(필터 전엔 승자가 파일마다 갈렸음).
  Wav2Vec2는 거의 무변화(-1.5%) — 환각형 오류가 없기 때문.

## 1. 실험 설계

| 항목 | 내용 |
|---|---|
| 데이터 | `master/master_audios/` CLIP1~4 (198.5s / 132.6s / 110.9s / 229.3s), 16kHz mono WAV로 변환 |
| GT | 실제 확보한 촬영 대본. 본문은 실제 발화와 거의 일치하나 인트로("시작합니다")·아웃트로 애드립은 대본에 없어 완전한 축어 전사는 아님(5.1절) |
| 비교 모델 | Faster-Whisper large-v3, Whisper large-v3-turbo, Seamless-M4T v2-Large, Wav2Vec2-XLSR-Korean (whisper-medium-ko는 로컬 모델 부재로 v2에서 제외) |
| 평가 | CER(주지표)·WER(보조), jiwer 기반. RTF는 워밍업 1회+측정 3회 평균, **CER/WER은 마지막 1회 결과로만 계산**(v1 설계 그대로 — Whisper 계열은 반복마다 환각 발생 여부가 갈릴 수 있음, 5.2절 참고) |
| 인프라 | RTX6000×2 (Quadro, Turing sm75), 격리 venv, 모델별 프로세스 GPU 라운드로빈 배정. GPU 핀닝은 물리 카드 UUID로 재확인함 |
| 환각 필터 | `evaluation/hallucination_filter.py` — (1) 상투구 denylist 제거 (2) 반복 어절·구 축약. 상세는 2절 |

## 2. 환각 필터 설계

STEP3_전처리팀이 `transcript_refine.py`에서 이미 만든 `DEFAULT_HALLUCINATION_PHRASES`를 그대로
재사용했다(다음 영상에서 만나요/뵙겠습니다, 시청해주셔서 감사합니다, 감사합니다, 구독과 좋아요, 구독, 아멘).
그 모듈은 발화 단위로 **태깅만** 하고 원문을 보존하는 설계(융합 LLM이 무시 힌트로 씀)인데, 여기는
CER/WER을 직접 재는 게 목적이라 실제로 **제거**하는 방식으로 재구현했다.

v2 실측에서 STEP3 denylist에 없던 상투구 2종을 추가로 관측해 정규식으로 추가했다:

- `MBC 뉴스 ○○○입니다` (Seamless-M4T-v2에서 반복 관측된 뉴스 앵커 클로징 환각)
- `한글자막 by ○○○` (Whisper turbo에서 관측된 유튜브 자막 크레딧 환각)

여기에 **반복 어절·구 축약**을 추가했다: 길이 1~10어절의 구가 2회 이상 연속 반복되면 1회로
줄인다(최소 반복 주기부터 탐색해 완전히 축약). "감사합니다"×26, "참기름"×7처럼 denylist에
없는 반복 루프, 문장 통째 반복(예: "화면이 나왔습니다."×2)까지 이 방식으로 잡힌다.

**한계(정직히 명시)**: denylist·반복축약 둘 다 "알려진 상투구" 또는 "반복"만 잡는다. 1회성이고
반복도 없는 환각(예: CLIP1 large-v3의 "김치찌개 계란 참기름..." 도입부, "마포구청 인터넷
방송국 홈페이지")은 반복 축약으로 부분적으로만(내부 반복된 "참기름"만) 줄어들고, 완전히 무관한
삽입 자체는 못 잡는다. 그래서 필터 후에도 CER이 0이 되지 않는다.

파이프라인 연결: `scripts/run_experiment_parallel.py --denylist-filter` 플래그로 실제 채점
전 단계에 연결됨(`run_all_models()`/`evaluate()` 등 v1 파일은 수정하지 않고, skip-scoring
모드와 동일한 방식으로 우회 호출). `--skip-scoring`과는 동시 사용 불가(채점 자체를 안 하므로).

## 3. 결과: 필터 전 / 후 나란히 비교

### 3.1 파일별 CER (전 → 후)

| 파일 | Faster-Whisper large-v3 | Whisper large-v3-turbo | Seamless-M4T v2-Large | Wav2Vec2-XLSR-Korean |
|---|---|---|---|---|
| CLIP1 | 1.0519 → **0.7926** | 0.8296 → **0.5630** | 0.8074 → **0.5556** | 0.8889 → 0.8889 |
| CLIP2 | 1.3921 → **1.2775** | 1.1189 → **1.0925** | 0.7269 → **0.6960** | 0.7357 → 0.7357 |
| CLIP3 | 0.1748 → 0.1748 | 0.3689 → **0.3107** | 0.5146 → **0.2136** | 0.5631 → 0.5631 |
| CLIP4 | 0.7317 → **0.0732** | 1.5935 → **0.1301** | 0.8049 → **0.0569** | 0.4797 → **0.4390** |

### 3.2 모델별 평균 (필터 전 → 후, 변화율)

| 모델 | CER 전 | CER 후 | 변화 | WER 전 | WER 후 | 변화 |
|---|---|---|---|---|---|---|
| Faster-Whisper large-v3 | 0.8376 | **0.5795** | **-30.8%** | 0.9906 | 0.7501 | -24.3% |
| Whisper large-v3-turbo | 0.9777 | **0.5241** | **-46.4%** | 1.0564 | 0.6858 | -35.1% |
| Seamless-M4T v2-Large | 0.7134 | **0.3805** | **-46.7%** | 0.9544 | 0.6041 | -36.7% |
| Wav2Vec2-XLSR-Korean | 0.6669 | 0.6567 | -1.5% | 1.1166 | 1.1077 | -0.8% |

> 필터 전 CER은 별도로 저장해둔 skip-scoring 전사(1개 샘플)로 재계산한 값이라, 2장(결과보고서
> 이전 버전)에 있던 Stage C 원 채점값과 소수점 단위로 다를 수 있다 — Whisper 계열은 워밍업+3회
> 반복 측정 중 마지막 1회만 채점에 쓰는데, 온도 폴백 때문에 반복마다 환각 발생이 갈린다(3.3절
> 계속). 이 표는 **같은 샘플**로 전/후를 재보정한 값이라 전/후 비교 자체는 self-consistent하다.

### 3.3 파일별 승자 — 필터 전 vs 후 (v1 선정룰: RTF≤0.10 통과 후 CER 최소)

| 파일 | 필터 전 승자 | 필터 후 승자 |
|---|---|---|
| CLIP1 | Whisper large-v3-turbo | **Seamless-M4T v2-Large** (0.5556, turbo와 근소차) |
| CLIP2 | Whisper large-v3-turbo | **Seamless-M4T v2-Large** (0.6960) |
| CLIP3 | Faster-Whisper large-v3 | Faster-Whisper large-v3 (0.1748, 유일하게 환각 없어 무변화) |
| CLIP4 | Wav2Vec2-XLSR-Korean | **Seamless-M4T v2-Large** (0.0569) |

(large-v3(비-turbo)는 CLIP1·2·4에서 RTF>0.10으로 v1 룰상 탈락 — RTF 자체는 필터와 무관해 전/후 동일)

**필터 전에는 파일마다 승자가 다 달랐는데(단독 우승 모델 없음), 필터 후에는 Seamless-M4T-v2-Large가
4개 중 3개에서 최저 CER로 뒤바뀌었다.** Wav2Vec2는 필터 전엔 평균 CER 1위였지만(환각이 없어서
숫자가 좋아 보였을 뿐), 필터 후엔 4종 중 유일하게 거의 개선이 없어 순위가 최하위로 내려간다 —
"환각 없음"이 "정확함"과 다르다는 걸 보여주는 사례.

## 4. 정성 분석 — 모델별 실패 유형

### 4.1 Whisper 계열(large-v3 / large-v3-turbo) — 상투구 환각

무음·잡음 구간에서 학습 데이터에 흔했던 문구를 지어낸다. 이번에 재현된 것:

```
CLIP1, turbo: "...다음 영상에서 만나요. 다음 영상에서 만나요. 다음 영상에서 만나요."
CLIP4, turbo: "...감사합니다" × 26회
CLIP1, large-v3: "...김치찌개 계란 참기름 간장 고춧가루 참기름×7 감자 참기름×4 마포구청 인터넷 방송국 홈페이지"
CLIP4, turbo: "...한글자막 by 한효정" (유튜브 자막 크레딧 환각, 2회 삽입)
```

STEP3_전처리팀이 이미 문서화한 "STT 환각 상투구(다음영상/감사합니다/아멘)"와 정확히 같은 계열.

### 4.2 Seamless-M4T-v2-Large — 뉴스 앵커멘트 환각 (가장 집요함)

"MBC 뉴스 ○○○입니다"류 뉴스 클로징이 클립 끝뿐 아니라 **문장 중간에도** 반복 삽입된다.
다른 모델은 대개 끝부분 한 곳에서 터지는데, 이건 전체에 산재:

```
CLIP1: "...전원 커터 순서가 있어요 이십사 핀 메인 먼저 Gpu 전원 -(기자) 커의 글을 듣고 글을
        니다. -(기자) MBC 뉴스 이재욱입니다. -(기자) MBC 뉴스 이재욱입니다."
```

한국어 뉴스 방송 데이터가 학습 데이터에 비중 있게 들어갔을 가능성을 시사한다.

### 4.3 Wav2Vec2-XLSR-Korean — 환각 없음, 대신 음절 붕괴

CTC(비자기회귀) 구조라 확신 없는 구간에서 그럴듯한 문장을 만들 능력이 없고, 그냥 음절이 깨진다:

```
CLIP1: "...전는 컨데터 순사가 있어요이십 사 핀 레인 먼저 집회요 전원요
        장말식토달차실언장정장 차문장문 줬다 격도문때때 언 말습니다 때 도 말이다"
```

이래서 denylist·반복축약 필터가 거의 안 먹힌다(3.2절, -1.5%) — 지어낸 게 없으니 걷어낼 게 없다.
**CER과 WER이 서로 다른 순위를 주는 이유**도 이것과 연결된다: CER은 글자 단위라 "산화막"→"사남이"처럼
음이 비슷하면 손해가 작지만, WER은 단어 단위라 그 단어가 통째로 오답 처리돼 wav2vec2가 WER은
4종 중 최하위다.

## 5. 한계

1. **GT 신뢰도** — 본문은 대본과 거의 일치하지만, 인트로("시작합니다")·아웃트로 애드립은 대본에
   없어 그 구간은 구조적으로 오류 처리된다. 완전히 공정하게 하려면 사람이 실제 음성을 들으며
   애드립까지 받아쓴 축어 GT가 필요하다.
2. **표본 크기** — n=4파일 × 모델당 1샘플. 통계적 유의성 없음(v1의 "n=5 구조적 유의 불가"와
   같은 성격). Whisper 계열은 반복 실행마다 환각 발생 여부가 갈리는 걸 직접 확인함(3.2절 각주) —
   최소 3~5회 반복 후 평균/최빈값으로 판단해야 신뢰할 수 있다.
3. **필터의 사각지대** — 2절에서 밝힌 대로, 반복되지 않는 1회성 환각(레시피·기관명 등 무관한
   삽입)은 이 필터로 못 걷어낸다. 필터 후에도 CER이 여전히 20~60%대인 이유 중 하나다.
4. **large-v3(비-turbo)** — 정확도 우위가 없는데 속도만 4~5배 느림(RTF 0.02~0.20, 파일 3개에서
   v1의 0.10 기준 탈락). 이번 후보군에선 탈락 검토 대상.

## 6. 권고

1. **본실험에서 Seamless-M4T-v2-Large를 유력 후보로 재검토** — 환각 필터 적용을 전제로 하면
   4파일 중 3파일 최저 CER. 단, 필터 없이 원본으로 쓸 경우 환각이 가장 심하다는 점도 같이 고지.
2. **본실험 전 필터 사각지대 보완** — 1회성 환각까지 잡으려면 denylist·반복축약보다 강한 방법
   (예: GT 없는 구간에서 "말이 안 되는 삽입" 을 잡는 별도 규칙, 혹은 LLM 기반 사후검증)이
   필요할 수 있다.
3. **GT를 축어 전사로 보강** — 인트로/애드립 구간까지 사람이 받아쓰면 CER 절대값이 지금보다
   더 낮아지고 모델 간 진짜 격차가 더 선명해질 것으로 예상.
4. **n을 늘려 재검증** — 최소 v1 수준(n≥5, 모델별 3회 이상 반복)으로 확대해야 3장 결론에
   통계적 근거를 붙일 수 있다.
