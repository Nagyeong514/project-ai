# 모션 가이드 샘플링 기반 암묵지 추출 파이프라인 보고서

**프로젝트:** 1인칭 AR 글래스 영상 → 전문가 암묵지 구간 자동 추출
**영상:** 컴퓨터 조립 전문가 1인칭 영상 (34.7분, 142MB)
**목적:** 무의미한 구간을 제거하고, 전문가의 암묵적 판단 과정이 담긴 구간만 추출하여 YOLO → STT → VLM 파이프라인의 입력으로 사용

---

## 1. 문제 정의

### 암묵지(Tacit Knowledge)란
전문가가 의식하지 못한 채 수행하는 행동 패턴. 언어로 설명하기 어렵지만 행동에서 드러난다.

**컴퓨터 조립 전문가의 암묵지 예시:**
```
부품 이상 감지 → 부품 재확인 → 매뉴얼 시선 → 타 부품 비교 → 원인 파악 후 손 이동
```
이 **시선의 순서와 패턴** 자체가 전문가의 문제 진단 과정이다.
초보자는 이 과정이 없거나 순서가 다르다.

### 1인칭 영상에서의 기술적 과제
AR 글래스로 촬영된 영상은 카메라 = 시선이므로:
- 카메라가 느리게 움직이다 멈추는 것 = 전문가가 무언가를 의도적으로 바라보는 것
- 카메라가 빠르게 흔들리는 것 = 단순 노이즈
- 카메라가 크게 연속 이동하는 것 = 걷기/이동

## 2. 접근 방법의 진화

### 2-1. 1단계: 모션 크기 기반 샘플링 (기존 방식)

**파일:** `motion_score.py`, `select_clip.py`, `run_pipeline.py`

세 가지 전략을 비교하여 최적 전략을 자동 선택:

| 전략 | 방식 | 특징 |
|------|------|------|
| A: Threshold + AKS | 상위 75% 모션 → 최소 간격 필터 | 너무 엄격, 3개만 선택됨 |
| B: CDF/MGSampler | 누적 분포 역변환 샘플링 | 모션 밀도 비례, 12개 |
| **C: AKS Window** | 시간 균등 분할 + 윈도우 ArgMax | **커버리지 최고, 최적 선택** |

**실험 결과 (전략 C 선택):**
- 클립 수: 12개
- 총 용량: 32.3MB
- 커버리지: 0~33.6분 (전체 영상 커버)

**한계:**
- 판단 기준이 "얼마나 많이 움직이는가"에만 의존
- 전문가 시선 탐색(느리게 이동 후 정지)이 낮은 점수를 받아 제거될 수 있음
- 걷기/카메라 흔들림이 높은 점수를 받아 포함될 수 있음
- **암묵지 구간을 구조적으로 감지하지 못함**

---

### 2-2. 2단계: 움직임 유형 분류 (motion_classifier)

**파일:** `motion_classifier.py`

"얼마나"가 아닌 **"어떻게" 움직이는가**로 판단 기준 전환.

**광학 흐름(Optical Flow) 기반 유형 분류:**

| 유형 | 판단 기준 | 처리 |
|------|----------|------|
| NOISE | 빠름 + 방향 산란 + 짧음 | 제거 |
| LOCOMOTION | 빠름 + 방향 일관 + 긴 지속 | 제거 |
| GAZE_SHIFT | 느린 이동 (0.8~4.0 pixel/frame) | **보존 (암묵지)** |
| FIXATION | 정지 + GAZE_SHIFT 직후 | **보존 (암묵지)** |
| IDLE | 정지 + 변화 없음 | 제거 |
| HAND_WORK | 손 감지됨 (MediaPipe) | **보존** |

**핵심 알고리즘 — GAZE_SHIFT → FIXATION 패턴:**
```
느린 시선 이동(GAZE_SHIFT) → [3초 이내] → 정지(IDLE)
                                              ↓
                                    FIXATION으로 승격 = 암묵지 후보
```

**방향 일관성 계산:**
Circular Mean Resultant Length 사용
- 모든 벡터 같은 방향 → 1.0 (이동, 의도적 시선)
- 사방으로 산란 → 0.0 (노이즈)

**실험 결과:**
| 유형 | 세그먼트 수 | 시간 | 판정 |
|------|------------|------|------|
| NOISE | 3,594개 | 8.3분 | 제거 |
| LOCOMOTION | 27개 | 0.9분 | 제거 |
| GAZE_SHIFT | 727개 | 11.3분 | **보존** |
| FIXATION | 21개 | 0.4분 | **보존** |
| IDLE | 303개 | 0.8분 | 제거 |

- 최종 추출 클립: **196개**
- 총 용량: 86.3MB
- 커버리지: 0.1분~34.5분 (전체 영상)
- 압축률: 54%

**문제점:**
- 196개는 후속 모델(YOLO/VLM) 입력으로 과도하게 많음
- 짧은 GAZE_SHIFT 세그먼트들이 개별 클립으로 분리됨
- HAND_WORK 구간의 커버리지 보장 없음

---

### 2-3. 3단계: 혼합 방식 ATKS (현재 개발 중)

**파일:** `atks.py`

motion_classifier의 유형 분류 + AKS Window Coverage의 균등 샘플링을 결합.

**처리 흐름:**
```
전체 구간
    ├─ GAZE_SHIFT + FIXATION → 전부 보존 (암묵지, 절대 손실 없음)
    ├─ HAND_WORK             → AKS Window로 대표 클립만 선별
    └─ NOISE / LOCO / IDLE  → 전부 제거
```

**HAND_WORK에 AKS Window를 쓰는 이유:**
손 작업 구간은 영상에서 가장 많은 시간을 차지하지만 전부 포함하면 과잉.
시간 균등 분할로 대표 장면만 추출하여 클립 수를 적정 수준으로 유지.

**설계 목표:**
- 암묵지 구간: 절대 손실 없음
- 작업 구간: 분당 1개 대표 클립
- 총 클립: 20~30개 목표

## 3. 방법론 비교

| 항목 | AKS Window (기존) | motion_classifier | ATKS (혼합) |
|------|-------------------|-------------------|-------------|
| 클립 수 | 12개 | 196개 | 목표 20~30개 |
| 암묵지 보존 | 우연적 | 구조적 | 구조적 + 보장 |
| 노이즈 제거 | 불완전 | 완전 | 완전 |
| 작업 커버리지 | 균등 | 불보장 | 균등 |
| 클립 수 적정성 | 너무 적음 | 너무 많음 | 적정 |
| 이론 근거 | Coverage 최적화 | 인지과학 fixation | 둘 다 |

```
│
├── motion_scores.csv        # 모션 점수 데이터
├── output_best_C/           # 기존 파이프라인 결과 (12개)
├── output_tacit/            # motion_classifier 결과 (196개)
└── output_atks/             # ATKS 결과 (생성 중)
```

## 5. 다음 단계

현재 파이프라인 출력(클립 mp4)을 아래 순서로 연결:

```
[완료] 모션 가이드 샘플링 → 클립 추출
    ↓
[다음] YOLO → 손/부품 객체 감지
    ↓
[다음] STT → 음성 텍스트 변환 (설명, 혼잣말 포함)
    ↓
[다음] VLM → 영상+텍스트 통합 분석
    ↓
[최종] 암묵지 후보 추출 및 구조화
```

**개선 방향:**
- STT 결과를 motion_classifier 피드백으로 활용 (전문가 발화 구간 = 보존 강화)
- 전문가/초보자 영상 비교 후 레이블링 → 학습 기반 분류기 전환
- AR 글래스 시선 추적 센서 데이터 연동 시 fixation 정확도 획기적 향상
