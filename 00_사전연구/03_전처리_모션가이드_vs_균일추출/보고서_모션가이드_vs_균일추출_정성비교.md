# 모션가이드 샘플링 vs 균일 프레임 추출 — VLM 행동 관찰 정성 비교

- 작성일: 2026-07-07
- 실험군: `master/motion_guieded_sampling/` 클립 15개 → 이 폴더(구 `master/EXP_motion_guided_vs_uniform`, 잡 2203)
- 대조군: 원본 영상 4개 전체를 균일 0.5fps로 추출한 기존 STEP4 산출물
  (`project-ai/STEP4_YOLO_VLM관찰/output/vlm_observations/`, 2026-07-06 실행분)
- 추론 설정 동일: YOLO best.pt / Qwen3-VL-8B nf4 / 0.5fps / chunk 40s / max_new_tokens 4000
  → **차이는 오직 "VLM에 어떤 프레임 구간을 넣었는가"에서만 발생**

## 1. 정량 개요 (비용·건수)

| | 모션가이드(실험군) | 균일 추출(대조군) | 차이 |
|---|---|---|---|
| 입력 | 클립 15개, 총 ~505s | 원본 4영상, 총 ~652s | 커버리지 77% |
| **총 프레임(=VLM 입력 비용)** | **253장** | **326장** | **-22%** |
| VLM generate 호출 | 15회(+빈청크 재시도 1) | 17청크 | 비슷 |
| 관찰 건수 | 75건 (CLIP별 31/19/9/16) | 82건 (21/17/23/21) | -9% |
| 관찰 밀도(건/프레임) | 0.30 | 0.25 | +18% |

프레임을 22% 덜 쓰고 관찰 건수는 9%만 적다 — 밀도로는 모션가이드가 우세.
단, 건수보다 아래 정성 차이가 본질이다.

## 2. 그룹별 정성 비교

### CLIP1 (정상 조립: 덮개→RAM 탈착/재장착→GPU 탈착/재장착) — **모션가이드 확실한 우세**

- **균일의 최대 결함이 그대로 드러난 그룹.** 마지막 청크(160s~)가
  "GPU 쿨링팬을 쥐고 치수 15cm 정도 아래쪽 방향으로 내립니다 **(x17)**" 반복 붕괴로 끝나,
  후반 GPU 재장착 마무리 구간의 정보가 통째로 소실됐다. 그 외에도 32~40s, 60~80s,
  114~160s에 관찰 공백(최대 46초).
- 모션가이드는 같은 영상에서 31건(vs 21건). 특히 **clip03이 케이블 3종을 개별 동작으로
  분리 포착**(팬 연결 코드 → SATA 데이터 케이블 → PCI-E 전력 케이블 순차 탈착) —
  균일 결과에는 이 케이블 작업이 아예 없다. clip04는 "전원 버튼을 누르고 → 즉시 RGB LED가
  백색으로 3회 깜빡인다"는 **조작→반응 인과 쌍**까지 잡았다.
- 해석: 원래 40초 청크 구조가 잡으려던 효과(짧은 구간 = 반복붕괴 방지)를, 모션가이드는
  "움직임이 실제로 있는 구간만으로 짧은 입력을 만드는" 방식으로 한층 더 강하게 실현한다.

### CLIP2 (GPU 케이블/탈거 → RAM) — **비슷, 모션가이드 소폭 우세**

- 건수 비슷(19 vs 17), 서사 흐름(케이블 당김 → GPU 탈거 → 보드 확인)도 양쪽 유사.
- 모션가이드 clip01이 "전원 버튼 누름 → 흰색 LED 3번 깜빡임"을 포착 — 균일에는 없음.
- 환각은 양쪽 모두 존재: 균일 "RAM을 주머니처럼 접어서 몸통 앞쪽으로 들고 움직임",
  모션가이드 "케이블 끝부분이 치수 조합 타입의 접촉 포인터로 변환됨". **모션가이드가
  환각을 줄여주지는 않는다**(VLM 자체 한계).
- 모션가이드 clip03은 반복 접힘(x9)으로 고유 문장 2건에 그침 — 클립 내 동작이 단조로우면
  짧은 클립도 반복붕괴를 피하지 못한다.

### CLIP3 (RAM 반복 재장착 연습 구간) — **균일 우세, 모션가이드 열세**

- 균일 23건 vs 모션가이드 9건으로 가장 큰 역전. 균일 쪽은 RAM 고정핀/클립 조작 디테일
  ("금속 클립을 왼손 엄지로 누르면서", "클립이 자동으로 닫힐 때까지")이 시간대별로 풍부하다.
- 모션가이드 3클립(27~28초)은 전부 초반 몇 초에 관찰이 몰리고 뒤가 반복 접힘(x5, x6)으로
  붕괴 — **같은 동작이 계속 반복되는 저다양성 구간에서는 모션가이드로 클립을 잘라도
  VLM이 새로 서술할 거리가 없어 이득이 사라진다.** 오히려 커버 시간 축소(83s/111s)만큼
  손해.

### CLIP4 (재부팅·BIOS 화면 조작) — **혼재: 최고 성과와 최악 실패가 공존**

- **모션가이드 clip03은 이번 실험 전체의 백미.** 키 입력→화면 반응이 2초 간격 쌍으로
  12건 완벽 정렬: "Enter 누름 → System Information 창 열림", "Page Down 누름 → CPU Model
  표시", "Esc 누름 → 초기 메뉴 복귀". 균일도 BIOS 구간을 잡긴 했지만(64~110s) 키-화면
  인과가 이렇게 촘촘히 짝지어지진 않았다. **행동인식 목적이라면 이 형태가 이상적 출력.**
- 반면 실패도 몰림: clip01 "스티커가 보인다 (x17)" 반복붕괴로 2건, **clip02는 temp 0.3
  재시도에도 관찰 0건**(원본 CLIP4에서 반복돼온 동결 패턴과 같은 계열 — 유일한 미해결
  리스크), clip04/05는 화면 정지 대기 구간이라 1건씩.
- 균일 쪽도 이 영상에선 [160s] "모니터 화면이 꺼져 있다 (x7)" 등 정지 구간 낭비가 컸다 —
  CLIP4는 어느 방식이든 어려운 영상이고, 차이는 "움직임 있는 구간(clip03)을 모션가이드가
  정확히 분리해냈다"는 것.

## 3. 종합 결론

1. **손 동작이 다양하게 이어지는 구간(CLIP1, CLIP2, CLIP4-BIOS 조작)에서는 모션가이드가
   명확히 우세** — 적은 프레임으로 더 조밀하고, 단계 완결적이며, 조작→반응 인과 쌍까지
   잡는 관찰을 만든다. 균일 추출의 최악 실패 모드(긴 영상 후반 청크의 반복붕괴로 구간
   통째 소실)를 클립 경계가 구조적으로 차단하는 효과가 크다.
2. **같은 동작이 반복되거나 화면 변화가 없는 구간(CLIP3, CLIP4 대기 구간)에서는 이득이
   없거나 열세** — 반복붕괴는 모션가이드로도 못 막고, 커버 시간이 줄어든 만큼 손해.
3. **비용은 프레임 기준 22% 절감**(253 vs 326장). 관찰 밀도(건/프레임)는 +18%.
4. **환각·반복붕괴는 양쪽 공통**(VLM 자체 특성) — 샘플링 방법으로 해결되는 문제가 아님.
5. 리스크: CLIP4_clip02 관찰 0건 동결 1건(6.7%). 원본 CLIP4 동결 이력과 같은 계열.

**요약 한 줄: 모션가이드 샘플링은 "행동이 있는 구간"을 잘라내는 본연의 목적 구간에서는
비용을 22% 줄이면서 관찰 품질을 올리지만, 반복·정지 구간에서는 균일 추출보다 정보가
줄어든다 — 행동 인식이 목적이면 채택할 가치가 있고, 전 구간 빠짐없는 기록이 목적이면
균일 추출(또는 병행)이 안전하다.**

## 4. 비교의 한계 (해석 시 주의)

- 모션가이드 클립들이 원본 전체를 커버하지 않는다(505s/652s = 77%). 따라서 "균일에만
  있는 관찰"의 일부는 샘플링 품질 차이가 아니라 **커버리지 차이**일 수 있다.
- 대조군은 영상당 1회 실행 결과라 VLM 출력의 실행 간 변동(빈 청크 재시도의 temp 0.3
  샘플링 등)은 통제되지 않았다.
- 관찰의 사실 정합성(실제 영상과 대조한 정답 검증)은 이 보고서 범위 밖 — 여기서는
  출력 구조·밀도·서사 완결성 기준의 정성 비교만 수행했다.
