Dell Precision 7920 Tower 정비 매뉴얼 (발췌)
문서번호: DP7920-SVC-04 / 대상: 서비스 엔지니어 / 시나리오: 조립 후 부팅(POST) 실패 진단

1. 조립 후 정상 조립 순서 (참고)
CPU0 장착 → 히트싱크 체결 → ECC RDIMM 장착 → HDD 캐리어 장착 → SATA0 케이블 연결
→ 전원·패널 커넥터 연결 → GPU 장착 → 전원 인가 후 POST 확인

2. 시스템 기본 조작 절차
본 장은 진단 및 조치 과정에서 공통적으로 수행되는 기본 조작을 규정한다.

2-1. 케이스 개방 및 작업 준비
본체를 테이블에 눕히고 측면 패널 래치를 당겨 케이스를 개방한다. 내부 부품이 잘 보이도록
본체 위치를 정렬한 후 작업을 시작한다.

2-2. 시스템 기동
전면 패널의 전원 버튼을 눌러 시스템을 기동한다. 전원 인가 시 전원 버튼 LED가 점등된다.

2-3. 메모리 모듈(RDIMM) 장착 기본 조작
DIMM 슬롯 양쪽 래치를 연 상태에서 모듈 하단의 노치를 슬롯 키에 맞춰 수직으로 삽입하고,
양쪽 래치가 잠길 때까지 모듈 상단을 고르게 누른다.

2-4. 케이블 연결 및 정리
각 전원 커넥터를 대응하는 포트에 연결한다. 연결 후 남는 케이블은 간섭이 없도록 정리한다.

2-5. BIOS 설정 화면 조작
POST 화면에서 F2 키를 입력하여 BIOS 설정 화면에 진입한다. 방향키로 항목을 이동하고
Enter 키로 선택하며, Page Down 키로 페이지를 이동한다. Esc 키를 누르면 현재 화면을
닫고 이전 메뉴로 돌아간다.

2-6. System Information 확인
BIOS 메인 화면에서 System Information 항목을 선택하면 메모리 총 용량, BIOS 버전,
CPU 모델 등 시스템 정보가 화면에 표시된다.

2-7. 모니터 및 화면 출력 확인
디스플레이 케이블 연결 후 모니터의 화면 출력 여부를 확인한다.

2-8. 메모리 인식 상태(용량·채널) 확인 — 표준 마무리 검증 절차
메모리 모듈 장착·교체 작업 후에는 BIOS 설정 화면의 System Information(및 Memory Settings)
항목에서 설치된 메모리가 정상적으로 인식되는지 아래 항목을 표준적으로 확인한다. 본 확인은
조립·교체 작업의 표준 마무리 검증 절차이며, 8항 최종 확인의 일부로 수행한다.
- 용량 인식 확인: 화면에 표시되는 메모리 총 용량이 실제 설치한 용량과 일치하는지 확인한다.
  용량이 설치값보다 적게 인식되면 모듈 미체결·불량 또는 슬롯 불량을 의심한다.
- 채널 인식 확인: 메모리 채널 구성이 정상(예: 듀얼/쿼드 채널)으로 인식되는지 확인한다.
  채널이 정상적으로 인식되지 않고 저하된 상태(예: 단일 채널)로 인식되면 메모리 대역폭이
  정상 대비 절반 수준으로 떨어져 성능이 크게 저하된다. 이 경우 2-3항·5항의 채널 순서
  (A1→A2→B1→B2) 장착 상태를 점검한다.
화면(디스플레이) 출력이 정상이더라도 위 용량·채널 인식값이 비정상이면 성능 저하 상태이므로,
화면 출력 확인과 별개로 반드시 BIOS에서 용량·채널 인식값을 확인한다.

3. 부팅 실패(POST 미통과) 최초 점검 절차
전원은 인가되나 화면이 출력되지 않고 POST를 통과하지 못하는 경우, 다음 순서로 점검한다.
1) 전원 케이블 및 메인보드 전원 커넥터(24핀 메인 전원, 8핀 CPU 보조전원), 전면 패널 케이블의
   결선 상태를 육안으로 재확인한다.
2) 결선에 이상이 없으면, 전원 버튼 LED 점멸 패턴을 확인하여 아래 진단 코드표에 따라
   고장 부위를 좁힌다.

4. 전원 버튼 LED 진단 코드표
| 점멸 패턴            | 의심 부위                     |
|-----------------------|-------------------------------|
| 황색 1회 + 백색 3회   | 메모리(RAM) 또는 프로세서 오류 |
| 황색 2회              | 확장 카드(PCIe) 오류           |
| 백색 지속 점등        | 정상 부팅 상태                 |

5. 메모리(RDIMM) 관련 오류 조치 절차
LED 패턴상 메모리 계열 오류로 판단되는 경우, 다음 절차로 조치한다.
1) 시스템 전원을 완전히 차단하고 전원 코드를 분리한다.
2) 정전기 방지 조치(ESD 스트랩 착용 등)를 취한다.
3) RDIMM을 슬롯에서 분리한다.
4) RDIMM을 지정된 채널 순서(A1 → A2 → B1 → B2)에 맞춰 재장착한다. 장착 방법은
   2-3항의 기본 조작을 따른다.
5) 전원을 인가하고 BIOS 설정 화면에 진입하여 메모리 총 용량이 정상적으로 인식되는지 확인한다.
6) 인식되지 않을 경우, 슬롯을 바꾸어 재장착하거나 정상 동작이 확인된 다른 모듈로 교체하여
   슬롯 또는 모듈 중 원인을 특정한다.

6. GPU 및 확장 카드 점검
GPU가 PCIe 슬롯에 완전히 안착되지 않으면 화면이 출력되지 않을 수 있다. 카드를 슬롯에서
분리한 후 고정 클립이 딸깍 소리가 날 때까지 재장착하고, 보조전원 케이블 연결 상태를 확인한다.

7. 모니터 및 디스플레이 출력 확인
디스플레이 케이블(DisplayPort/HDMI)이 GPU 또는 메인보드 출력 포트에 정확히 연결되어
있는지 확인하고, 모니터 자체의 입력 소스 설정이 올바른지 점검한다.

8. 조치 후 최종 확인
모든 조치 완료 후 재부팅하여 POST 통과 여부와 BIOS 상의 메모리/장치 인식 상태를 최종
확인한다. 정상 부팅이 확인되면 진단을 종료한다.

※ 유의사항
- 본 매뉴얼은 RDIMM "탈거 → 재장착"을 표준 절차로 규정하며, 접점 세척(지우개, 알코올
  솜 등 이용) 절차는 정식 절차에 포함되어 있지 않다. 접촉 불량이 반복적으로 의심되는
  경우 정식 절차상으로는 모듈 교체를 우선 권장한다.
- 본 매뉴얼에는 슬롯 재배치 시 "작업자가 손에 익은 순서" 같은 개인화된 기준은 규정하고
  있지 않으며, 채널 순서(A1→A2→B1→B2)만을 표준으로 규정한다.
