# 전처리 파이프라인 분석 데이터 명세

## 1. 구간 분류 요약표

| CLIP | 구간 분류 | 핵심 포착 내용 |
| :---: | :--- | :--- |
| **1** | CPU 소켓 정렬 | ⚪ 안중요+침묵 핀 방향 맞추는 시선 |
| **1** | 써멀 도포 | 🔵 중요+침묵 ★도포량 조절 손동작 |
| **1** | 나사 대각선 조임 | ⚪ 안중요+침묵 순서 패턴 |
| **1** | RAM 슬롯 라벨 응시 | 🔵 중요+침묵 ★슬롯 색상 확인 시선 |
| **1** | POWER2 커넥터 당겨보기 | 🔵 중요+침묵 ★촉각 확인 제스처 |
| **2** | LED 패턴 응시 | 🔵 중요+침묵 ★패턴 판독 시선 |
| **2** | 케이블 전체 확인 | 🔵 중요+침묵 ★커넥터 누르고 당기는 손 |
| **2** | 케이블 확인 후 판단 | ⚪ 안중요+침묵 사고 시간 포착 |
| **2** | RAM 탈거 | 🔵 중요+침묵 ★래치 동시 탈거 손 모양 |
| **3** | RAM 단자 세척 | 🔵 중요+침묵 ★지우개 닦기 손동작 (가장 가까이) |
| **3** | 래치 재확인 제스처 | ⚪ 안중요+침묵 잠금 확인 당기기 |
| **3** | 슬롯 라벨 재응시 | 🔵 중요+침묵 ★채널 판단 시선 |
| **4** | BIOS 수치 응시 | 🔵 중요+침묵 ★메모리 용량 확인 시선 |

> 💡 **참고사항:** `🔵 중요+침묵 ★` 항목은 총 9개로, 발화(소리) 외에 작업자의 행동이나 시선 속에 숨겨진 노하우가 있는지 검증하는 핵심 구간입니다.

## 2. 암묵지 정답지

| 타임라인 | 발화 내용 | 암묵지 내용 |
| :--- | :--- | :--- |
| **CLIP 1 — 01:40**<br>(RAM 슬롯 응시) | (침묵) | 슬롯 라벨과 색상으로 채널 구성을 먼저 파악한 뒤 삽입한다. 초보자는 이 단계를 생략하고 아무 슬롯에나 꽂는다. |
| **CLIP 1 — 02:50**<br>(POWER2 확인) | (침묵) | 커넥터를 눈으로 보는 것만으로 끝내지 않고, 손으로 눌러 촉각으로 연결 상태를 재확인한다. |
| **CLIP 2 — 00:05~00:30**<br>(LED 응시) | “황색 한 번, 백색 세 번. 이 패턴이면 RAM 쪽이야.” | LED 깜박임 패턴을 끝까지 읽고 원인을 RAM/CPU 계통으로 즉시 좁힌다. 초보자는 패턴을 보고도 의미를 해석하지 못한다. |
| **CLIP 2 — 00:40~01:20**<br>(케이블 확인) | “원인 좁히기 전에 일단 다 봐요.” | 특정 부품을 의심하기 전, 연결 상태 전체를 체계적으로 먼저 점검한다. 커넥터를 누르고 당겨보는 촉각 확인이 포함된다. |
| **CLIP 2 — 02:10**<br>(RAM 탈거) | “래치 두 개 동시에 눌러야 해요.” | 래치를 양쪽 동시에 눌러야 안전하게 탈거된다. 한쪽만 누르면 슬롯 핀이 파손될 수 있다. |
| **CLIP 3 — 00:05~01:00**<br>(단자 세척) | “새 부품이라도 단자는 한 번 닦아야 해요.” | RAM 단자의 산화막 제거가 교체보다 우선이다. 부품 교체를 고려하기 전에 세척이 먼저다. |
| **CLIP 3 — 01:10**<br>(래치 잠금 확인) | “클릭 소리 두 번 들려야 해요.” | 래치 잠금 상태를 청각(클릭 소리)과 촉각(당겨보기)으로 이중 확인한다. 눈으로만 보지 않는다. |
| **CLIP 3 — 02:00**<br>(슬롯 라벨 재응시) | “이 색이 A채널, 저 색이 B채널이에요.” | 슬롯 색상과 라벨로 채널 구성을 즉시 파악한다. 워크스테이션(6채널 구조) 전용 지식으로, 초보자는 인지하지 못한다. |
| **CLIP 4 — 00:30~01:00**<br>(BIOS 수치 확인) | “채널 오인식이면 성능이 절반으로 날아가요.” | 부팅 성공만으로 완료로 인식하지 않는다. BIOS 메모리 용량과 채널 구성 수치를 반드시 최종 확인한다. |
